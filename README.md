# 🍺 BG Советник — локальный LLM-помощник для Hearthstone Battlegrounds

Оверлей поверх Hearthstone, который читает `Power.log`, отслеживает состояние
Полей сражений (магазин Боба, доска, рука, золото, тир таверны, здоровье)
и даёт советы по закупке через локальную LLM (Ollama). Игра за вас **не играет** —
только подсказывает, поэтому риска бана нет.

## Состав

| Файл | Назначение |
|---|---|
| `main.py` | точка входа: лог-наблюдатель + оверлей + советник |
| `log_watcher.py` | парсер Power.log (сущности, фазы, магазин, доска) |
| `advisor.py` | сборка промпта и запрос к Ollama |
| `overlay.py` | полупрозрачное окно поверх игры (PySide6) |
| `bg_db.json` | база знаний: стратегические заметки + существа (пополняется) |
| `config.json` | настройки (модель, путь к логам, оверлей) |
| `test_parser.py` | офлайн-проверка парсера на существующем логе |
| `test_e2e.py` | сквозной тест: лог → совет LLM |

## Установка (уже сделано на этом ПК)

```bat
pip install -r requirements.txt
ollama pull qwen3:8b
```

## Запуск

1. Запустите сервер Ollama: `ollama serve` (или просто запущенное приложение Ollama в трее).
2. Запустите советника: `python main.py` (или двойной клик по `run.bat`).
3. Запустите Hearthstone и начните партию Полей сражений.
4. Окно-оверлей появится поверх игры: состояние обновляется само,
   совет — по кнопке «💡 Совет» или автоматически при начале закупки
   (настраивается `auto_advice` в `config.json`).

Играйте в оконном или оконном безрамочном режиме — в эксклюзивном
полноэкранном режиме оверлей не виден.

## Настройки (`config.json`)

- `hearthstone_logs_dir` — папка логов HS (уже прописана: `G:\Hearthstone\Logs`);
- `ollama_url`, `model` — адрес Ollama и модель (по умолчанию `qwen3:8b`);
- `auto_advice` — автоматически спрашивать совет при смене магазина;
- `overlay` — прозрачность, ширина, «поверх всех окон».

## Как это работает

- Логирование Power включается файлом `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config`
  (у вас уже включено). Логи пишутся в `Logs\Hearthstone_<дата_время>\Power.log`.
- Парсер следит за самым свежим Power.log и строит состояние: фаза
  (закупка/бой по `BACON_CURRENT_COMBAT_PLAYER_ID`), золото (`RESOURCES - RESOURCES_USED`),
  тир (`PLAYER_TECH_LEVEL`), магазин (существа Боба с тегом `HAS_DRAG_TO_BUY`),
  доска и рука (по зонам и контроллеру).
- Советник отправляет состояние + стратегическую справку из `bg_db.json`
  в локальную модель и показывает краткий совет на русском.
- Ответ валидируется: несуществующий «тир 7», ап при максимальном тире и
  небьющаяся арифметика золота ловятся автоматически, модель получает
  ошибку и отвечает заново (1 повтор). Стоимость апов таверны —
  `tavern_upgrade_costs` в `config.json`.

## Ограничения v1

- Советы зависят от силы модели: 8b заметно умнее 7b, но всё равно может ошибаться
  в деталях (проверяйте советы на здравый смысл); можно поставить модель крупнее
  (`qwen3:14b`, если хватит VRAM/RAM — на 8 ГБ видеокарте будет CPU-offload и медленнее).
- Заморозка лавки и составы оппонентов пока не учитываются.
- Если советник запущен посреди партии, состояние достроится со следующей партии
  (или со следующего большого дампа состояния).
- База `bg_db.json` обновлена под патч 37.0.2 (2026-11-03) по официальным
  патчноутам Blizzard. После следующих патчей дополняйте `meta_notes_ru`,
  `strategy_ru` и `minions` — советы станут точнее.
